# 交接 · 视觉原型（前端）

游戏团队开发中的「一句话交接」体验设计项目——前端视觉层与素材。

## 这个仓库里有什么

```
视觉功能.html            带功能的视觉原型（单文件，可直接打开）
视觉前端.html            纯布局 / 调试台版本，可导出 视觉布局.json
视觉功能使用说明.txt      快捷键与调试台用法
前端视觉素材/            木桌隐喻的全套素材（主界面、交接卡、侧边栏按钮、扑克牌）
.cursor/                编辑约定（只改视觉，不动核心层）
```

## 怎么打开

双击 `视觉功能.html` 即可，无需构建、无需服务器。
素材用相对路径引用，**整个文件夹一起移动**才能正常显示。

## 代码结构（重要）

`视觉功能.html` 是单文件自包含，分三段：

| 区段 | 说明 |
|---|---|
| CONFIG | 常量与 localStorage 键 |
| CORE | 业务核心：action 表、dispatch、状态机。**不碰 DOM**，与定稿原型逐行同源 |
| VIEW | 视图与交互：场景布局、卡片 3D、标定台、共创涂画 |

改视觉只动 VIEW 与 CSS；CORE 里的规则（提交锁定、接受才落卡、打回次数单调等）不要改，改了会和设计规格对不上。

## 状态存储

浏览器 localStorage，四个键：`handoff-visual-v1`（业务状态）、`handoff-visual-layout-v2`（布局标定）、`handoff-visual-project`（项目管理）、`handoff-visual-cocreate`（共创涂画）。清空对应键即可重置。

## 状态

视觉层可交互演示；数据为前端模拟，未接真实文件系统与后端。
