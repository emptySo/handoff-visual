## 不要用自动布局，也不要套娃画框

幻灯片本身是唯一的画框：一页一个 `1920×1080` 的 Frame。页里面不要再放 Frame。

卡片、图位、行列和数字都用 **Group**。组和组可以嵌套。需要底色、描边或圆角时，在组里放一个 Rectangle，不要用 Frame 当底板。Group 本身没有填充和圆角。

定位用绝对坐标。不要调用自动布局，也不要给子元素设 `FILL` 去吃剩余空间。自动布局会把图位拉成扁条。

图位按真实截图的比例单独定宽高，不跟着父级变高或变宽：

- 报告、帖子、文章截图用 **4:3** 横图，例如 `560×420`、`480×360`、`320×240`。
- 界面线框用 **3:4** 竖图，例如 `400×533`。
- 宽高比落在 **3:4 到 16:9** 之间。短边至少 **220**。
- 宽超过高的两倍，或高超过宽的两倍，都算扁条，不能用作图位。

## 安全换行

改一段会换行的文字时，只动这一段的宽度和高度：

1. `loadFontAsync` 该节点正在用的 `Noto Sans SC` 字重。
2. `textAutoResize = 'NONE'`。
3. `resize(目标宽度, 4000)`。
4. `textAutoResize = 'HEIGHT'`。这时 `height` 才是真实行高。

不要在 `HEIGHT` 之后调用 `resize(宽度, 10)` 这类小高度。这个环境会把文字框裁成那个高度，卡片会跟着塌下去。

8 个字以内的标签保持 `WIDTH_AND_HEIGHT`，不要拉成卡片全宽。
